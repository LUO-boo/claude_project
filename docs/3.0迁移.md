# 用户引导

1.  顶部导航栏增加【分销3.0】菜单，下方有两个二级菜单：店长搬家、店长下单。点击店长搬家，跳转到新版搬家，点击店长下单，跳转到新版下单
    
2.  ai改图王和闪购的new标去掉
    
3.  新用户进入只看到分销3.0菜单，代发菜单隐藏
    
    
4.  上线后，用户每日首次进入超级店长，弹出引导弹窗。弹3次。
    
    1.  点击【去搬家】，新开页面，跳转到新版搬家，点击【去下单】，新开页面跳转到新版下单
        
    2.  点击蒙层或关闭按钮可关闭弹窗。关闭后有个收起的动画效果，收起到分销3.0菜单
        
    
5.  用户从1688买家端授权跳转，做判断，若是新用户，进入新版（有分销菜单，没有代发菜单）。若是老用户，保持现状
