# AI填充商品标题（功能模块）

## 白名单用户（业务分类）

### 权限验证（功能点）

- 访问闪购菜单可见并可操作
  - 前置条件：环境：用户在白名单中，已登录千牛或浏览器；数据：无
  - 测试步骤：进入系统 → 查看顶部菜单栏 → 点击【闪购】菜单
  - 期望输出：1. 可见【闪购】一级菜单；2. 可点击进入；3. 左侧显示【闪购商品】菜单
  - 用例编号：TC-白名单用户-001
  - 优先级：P0

- 直接URL越权访问分销菜单被拦截
  - 前置条件：环境：用户在白名单中，已登录；数据：已知分销3.0菜单URL
  - 测试步骤：在浏览器地址栏直接输入分销3.0菜单URL → 按回车访问
  - 期望输出：1. 页面拦截并弹出提示："无访问权限"；2. 停留在当前页面，不跳转
  - 用例编号：TC-白名单用户-002
  - 优先级：P0

### 列表展示（功能点）

- 已上架闪购商品显示在列表中
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：店铺存在至少1条已上架闪购商品
  - 测试步骤：查看商品列表
  - 期望输出：已上架闪购商品显示在列表中，包含商品主图、标题、商品ID、是否优化过字段
  - 用例编号：TC-白名单用户-003
  - 优先级：P0

- 已下架闪购商品也显示在列表中
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：店铺存在至少1条已下架闪购商品
  - 测试步骤：查看商品列表
  - 期望输出：已下架闪购商品显示在列表中（不区分上下架）
  - 用例编号：TC-白名单用户-004
  - 优先级：P1

- 非闪购商品不显示在列表中
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：店铺存在至少1条非闪购商品
  - 测试步骤：查看商品列表
  - 期望输出：非闪购商品不显示在列表中
  - 用例编号：TC-白名单用户-005
  - 优先级：P1

- 店铺无闪购商品时展示空状态
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：店铺下无任何闪购商品
  - 测试步骤：查看商品列表
  - 期望输出：显示空状态提示："暂无数据"
  - 用例编号：TC-白名单用户-006
  - 优先级：P2

### 单条优化-基础流程（功能点）

- 点击优化标题AI生成成功并显示编辑态
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：列表存在至少1条商品
  - 测试步骤：点击某商品的【优化标题】按钮 → 等待生成完成
  - 期望输出：1. 生成过程中输入框不可编辑，显示"优化中"；2. 生成完成后输入框变为可编辑状态；3. 输入框上方显示原标题；4. 显示【使用】【复原】【生成记录】按钮
  - 用例编号：TC-白名单用户-007
  - 优先级：P0

- 点击使用保存新标题并更新状态
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，生成完成且输入框为编辑态；数据：生成结果≤60字符
  - 测试步骤：点击【使用】按钮
  - 期望输出：1. 提示"保存成功"；2. 输入框变为置灰不可编辑状态；3. 列表"是否优化过"字段更新为"已优化"
  - 用例编号：TC-白名单用户-008
  - 优先级：P0

- 点击复原恢复原标题
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，生成完成且输入框为编辑态；数据：无
  - 测试步骤：点击【复原】按钮
  - 期望输出：1. 恢复原标题；2. 输入框变为置灰不可编辑状态
  - 用例编号：TC-白名单用户-009
  - 优先级：P1

- AI生成失败提示错误信息
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：AI服务异常或返回错误
  - 测试步骤：点击【优化标题】按钮 → 等待响应
  - 期望输出：1. 提示错误信息："生成失败，请稍后重试"；2. 输入框保持不可编辑状态
  - 用例编号：TC-白名单用户-010
  - 优先级：P1

- 网络超时提示连接失败
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：网络延迟或断网（使用Charles断网）
  - 测试步骤：点击【优化标题】按钮 → 等待响应
  - 期望输出：提示"网络连接失败，请检查网络后重试"
  - 用例编号：TC-白名单用户-011
  - 优先级：P1

### 单条优化-生成记录（功能点）

- 查看生成记录气泡展示最近5次
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，输入框为编辑态；数据：已生成至少1次标题
  - 测试步骤：点击【生成记录】按钮
  - 期望输出：1. 弹出气泡；2. 展示最近5次生成记录（如果不足5次则展示实际次数）
  - 用例编号：TC-白名单用户-012
  - 优先级：P2

- 点击使用生成记录填充到输入框
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，生成记录气泡已打开；数据：存在至少1条生成记录
  - 测试步骤：点击某条记录的【使用】按钮
  - 期望输出：1. 记录填充到输入框；2. 可继续编辑；3. 气泡关闭
  - 用例编号：TC-白名单用户-013
  - 优先级：P2

- 二次触发生成保留之前的生成记录
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：已生成至少1次标题
  - 测试步骤：再次点击【优化标题】按钮 → 生成完成 → 点击【生成记录】
  - 期望输出：1. 保留之前的生成记录；2. 新增本次记录；3. 总记录数≤5条
  - 用例编号：TC-白名单用户-014
  - 优先级：P2

  - 测试步骤：点击【使用】按钮
  - 期望输出：1. 提示"保存成功"；2. 状态更新为"已优化"
  - 用例编号：TC-白名单用户-015
  - 优先级：P0

- 生成结果为59字符正常使用
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：AI生成结果=59字符
  - 测试步骤：点击【使用】按钮
  - 期望输出：1. 提示"保存成功"；2. 状态更新为"已优化"

  - 优先级：P1

- 生成结果为58字符正常使用
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：AI生成结果=58字符
  - 测试步骤：点击【使用】按钮
  - 期望输出：1. 提示"保存成功"；2. 状态更新为"已优化"

- 生成结果超过60字符标红提示并置灰使用按钮

  - 用例编号：TC-白名单用户-018
  - 优先级：P0

- 手动删减至60字符内使用按钮高亮可用

- 手动编辑后超60字符标红提示

  - 测试步骤：手动增加1个汉字
  - 期望输出：1. 标题标红提示；2. 【使用】按钮置灰不可点击
  - 用例编号：TC-白名单用户-020
  - 优先级：P1

- 字符计数规则验证
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，输入框为编辑态；数据：无
  - 测试步骤：输入30个汉字 → 查看字符计数
  - 期望输出：显示60个字符（汉字/中文标点计2字符，英文数字计1字符）
  - 用例编号：TC-白名单用户-021
  - 优先级：P1

### 批量优化（功能点）

- 批量生成标题每次优化5条并显示优化中
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：已选择10条商品
  - 测试步骤：点击【批量生成标题】按钮 → 观察生成过程
  - 期望输出：1. 从上到下顺序优化；2. 每次优化5条；3. 对应5条输入框显示"优化中"
  - 用例编号：TC-白名单用户-022
  - 优先级：P1

- 批量确认使用保存标题并更新状态
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，批量生成完成；数据：已选中至少1条商品，且生成结果≤60字符
  - 测试步骤：点击【批量确认使用】按钮
  - 期望输出：1. 批量保存新标题；2. 状态更新为"已优化"；3. 提示"批量保存成功"
  - 用例编号：TC-白名单用户-023
  - 优先级：P1

- 部分商品批量操作未选中商品不受影响
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面；数据：列表存在10条商品，仅选择前3条
  - 测试步骤：选择前3条商品 → 点击【批量生成标题】 → 等待生成完成
  - 期望输出：1. 仅前3条商品生成标题；2. 其余7条不受影响，未生成标题
  - 用例编号：TC-白名单用户-024
  - 优先级：P1

- 仅支持当前页选择切换页面后选择不保留
  - 前置条件：环境：白名单用户，已登录，已进入标题优化页面，商品分布在多页；数据：共30条商品，每页显示20条
  - 测试步骤：在第1页选择5条商品 → 切换到第2页 → 查看选择状态
  - 期望输出：1. 第1页选择不保留；2. 不支持跨页选择
  - 用例编号：TC-白名单用户-025
  - 优先级：P2

### 筛选查询（功能点）

  - 用例编号：TC-白名单用户-026

- 商品ID批量精确查询返回匹配列表
